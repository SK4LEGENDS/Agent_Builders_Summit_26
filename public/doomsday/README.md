# Doomsday background (Protocol 616)

Drop your full-site background image here:

## File name

**`bg.jpg`** (preferred)

Also works with any common extension using the same base name:

- `bg.png`
- `bg.jpeg`
- `bg.webp`
- `bg.gif`
- `bg.avif`
- …

## Path

`public/doomsday/bg.jpg`

Example full path on your machine:

`d:\SJIT\PEPE_RPA\PEP-RPA-SDC-SUMMIT--master\public\doomsday\bg.jpg`

When someone types **616**, particles turn off and this image becomes the site background.
