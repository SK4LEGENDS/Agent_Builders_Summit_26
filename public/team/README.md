# Team photos (Protocol 616 · TVA ID cards)

Drop member headshots here. Filenames should match the `image` field in `src/data/team.ts`.

## Naming

Use the slug without extension, e.g.:

- `member-01.jpg`
- `member-02.png`
- `member-03.webp`

The site accepts common image formats automatically:

`png` · `jpg` · `jpeg` · `webp` · `gif` · `svg` · `avif` · `bmp` · `jfif` · `ico` · `tif` · `tiff` · `heic` · `heif`

## Tips

- Prefer **portrait** headshots (face centered / upper body).
- Cards apply a yellow/sepia grade so photos match the black & amber TVA badge.
- Recommended size: ~800×1000 or larger.
