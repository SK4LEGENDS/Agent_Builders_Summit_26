# Speaker images

Drop portrait photos here. The site accepts **any common image type** and resolves them automatically.

## Supported formats

`png` · `jpg` / `jpeg` · `webp` · `gif` · `svg` · `avif` · `bmp` · `jfif` · `ico` · `tif` / `tiff` · `heic` / `heif`

You can use any of these for a speaker even if `src/data/speakers.ts` lists `.jpg` — the site will try the listed file first, then the other formats with the same base name.

## Expected base names

| Base name | Speaker |
|-----------|---------|
| `treesa` | Treesa |
| `palani` | Palani |
| `kirubakaran` | Kirubakaran |
| `priya-sharma` | Dr. Priya Sharma |
| `arjun-mehta` | Arjun Mehta |
| `lakshmi-narayanan` | Lakshmi Narayanan |
| `kavitha-rajan` | Kavitha Rajan |
| `vikram-singh` | Vikram Singh |
| `ananya-krishnan` | Ananya Krishnan |
| `rahul-verma` | Rahul Verma |
| `meera-iyer` | Meera Iyer |

Example: `treesa.png`, `treesa.webp`, or `treesa.jpg` all work.

## Tips

- Prefer portrait crop (~3:4)
- Recommended size: **800×1060** or larger
- Until a file exists, a styled placeholder is shown
