# Brand logos

Place the society / summit logo here. Dark logos (black tiles) are framed so they stay visible on the light header and footer.

## File name (any of these)

- `abs-logo.png` (preferred)
- `logo.png`
- `rpa-logo.png`
- `rpa-society.png`

Any common extension works: `png`, `jpg`, `jpeg`, `webp`, `svg`, `gif`, `avif`, …

## Tips

- Square crop works best
- Recommended size: **256×256** or larger
- Your black RPA Society mark will fill the tile edge-to-edge
